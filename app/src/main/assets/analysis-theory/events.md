# 应事模块 · 应什么事

版本：3。用途：在人物对应已经确定后，推导这个人处于什么状态、对谁产生什么影响、可能发生什么事。人物如何确定，由“人物对应模块”负责。

## 1. 接收人物对应，保留原始依据

接收具体人物、对应干支、十神、所在宫位和对应理由。父亲就是父亲，母亲就是母亲；保留原始十神名称，不先换成“资源”“约束”等词再猜人事。没有确定的人物不能在应事过程中临时补定，更不能为了贴合反馈换人。

## 2. 形成力量结论，再解释人物状态

从全局判断所对应五行的实际状态：月令与季节、透藏、通根及根的深浅和是否受损、生扶来源、克泄耗、位置远近与作用能否接续、寒暖燥湿，以及其他干支参与后的合冲刑害破。十二长生注明采用的规则，结合月令、根气和实际作用判断，不凭一个“旺”或“墓”代替结论。

条件必须做取舍：哪一项起主导作用，哪一项抵消或缓解，最终力量能否发挥、能否持续、受制到什么程度。既不能有这个五行就认定有力，也不能见克便认定克得动；见合要区分合而不化、牵制及成化条件。不能只列条件，末尾加一句“注意”。

先写明确的综合结论，再据此讨论人物自己的处境；保留支持结论和反对结论的关键依据，以及最终取舍理由。

## 3. 分开判断本人状态与对命主的作用

同一个人物需要回答两件事：他自身过得怎样；他对命主做了什么、产生什么结果。例如父亲的经济状况与父亲能给多少支持分别判断；母亲参与照顾与这种照顾是否有益分别判断。

有作用、作用有力、结果有益，是三个不同判断。力量强不直接等于家境好，生扶不直接等于获益，受克也不直接等于发生坏事。

## 4. 用完整作用关系判断人与人的关系

同时检查双方力量、各自生扶与制约的来源、第三方介入、作用距离和能否转接，明确最终是谁影响谁、影响方式及程度。不能截取一对干支的生克就结束。

例如讨论父母关系，必须解释双方实际作用及其他干支如何加重、缓解或改变这种作用。不能把“水克火”直接写成父母争吵，更不能直接升级为打架。具体事件需要比五行关系更完整的推导。

## 4.1 多方作用与结果推导（E-R01）

归属：应事模块的通用分析路径。用于分析多个参与方共同作用后发生什么变化，不以某一种家庭关系或某一个事件命名。人物对应由独立模块提供；路径已采纳不等于预测准确性已验证。

第一步，明确本次要判断的问题与此前状态。接收已确定的人物对应、原始干支和十神、所处宫位、前层状态及时间范围。列明谁参与、各方当前处境、待判断的结果是什么。对应尚未确定时保留候选，不为得到某个事件临时换人。

第二步，逐方形成实际力量结论。综合月令、通根及根是否受损、透藏、生扶和克泄耗、寒暖燥湿、位置与作用距离，明确各方靠什么发挥作用、在哪里受限。双方有根不等于势均力敌，同属一类不等于互助，存在生克关系不等于已经有效作用。必须取舍主次，说明为何某项条件在此处更关键。

第三步，追踪完整作用过程。分别检查双方直接作用、经第三方转接的间接作用，以及其他干支对施力者和承受者的生扶、牵制与耗用。共同来源只提供需要检查的关系，不直接指定现实行为。每一条作用都要回答：谁作用于谁，改变了对方的哪项条件，作用能否到达并持续；不能用干支名称相同代替实际接续。

第四步，比较同时存在的不同作用。施生或施制之外，加入方还可能耗用自身、增强对手、改变根气、形成牵合或满足合化条件。将这些影响放回同一全局，判断谁的作用能够落实、谁被抵消、哪条关系成为主导。不可将所有路径独立翻译成事件后并排输出，也不可将合、冲、生、克固定标成吉或凶。

第五步，比较作用前后的状态。逐项说明各方力量、彼此关系、可采取的行动和此前障碍发生了什么改变，哪些条件仍保留。区分当次行为被停止与造成该行为的条件被改变，区分一方获益与双方关系改善。结论必须能追溯到实际发生变化的条件，不能用“有帮助”“有压力”代替。

第六步，判断结果持续性。追踪作用来源继续存在、减弱或退出后，变化能否由新的根气、支持或关系维持。若只在外力存在时有效，而原有作用条件未变，只能提出暂时改变的候选；若关键条件已经改变，才讨论持续结果。重复发生必须另有原有条件继续起作用或重新被触发的依据，不能从一次介入直接推出反复。

第七步，由完整组合形成具体应事假设。结合人物、宫位、时间与上述净作用结果，写出谁采取什么行动、对谁或何事产生什么结果。原始十神名称与作用分析保留，不先将每个十神换成固定人事词再拼句子。若同一结构支持多个候选，写明哪些依据使其中一个更优、哪些关键差别尚无法判断，不为凑具体事件添加没有依据的细节。

第八步，分开核对结构判断、事件假设与反馈。先固定假设和区分候选的观察点，再接收反馈；按人物对应、力量取舍、作用方向、转接条件、持续性或具体取象定位错误。认可路径不等于确认事件；确认一次事件不等于通用规则验证。校正规则后用未参与该次修改的案例或后续事件检验，保留失败记录，不能用同一个反馈同时改规则又证明规则准确。

输出顺序：原有状态 → 各方实际力量 → 完整作用及主次取舍 → 前后条件变化 → 结果及持续性 → 具体应事假设 → 区分候选的依据与反馈。各层承接前层，不从头重套事件句子。

维护原则：具体命例用于检验、反证和修正上述步骤，不逐个积累为“某组合必应某事”的事件词典。新案例优先检查能否由已有路径解释；只有发现现有路径遗漏了明确的作用机制，才修订路径，而不是新增一个事件模板。

## 5. 宫位确定讨论范围，全局确定实际作用

年柱、月柱可用于讨论早年家庭背景，但日柱、时柱仍参与力量判断。年支所处的位置不能代替它在全局中的实际状态，也不能脱离其他干支独断家境。

将人物对应、宫位、综合力量及作用结果一起使用，明确结论说的是父亲、母亲、亲属还是命主本人，说的是经济、相处、照顾还是教育。不能用“资源分配并存”一类笼统词替代具体判断。

## 6. 每一层承接前一层，并形成自己的结果

原局 → 大运 → 流年 → 流月 → 流日 → 流时。后层接收前层的完整状态，判断新干支加入后，原有生扶、制约、通根、组合和人物关系如何改变。不能每层重套相同的句子，也不能把各层拆成互不相关的预测。

每层都可以形成对应时间范围的应事判断：先说明此前基础，再说明本层改变了什么，最后给出本层结果。年月日时判断分别保留；小时变化不能覆盖此前的年月结论，也不能因为组合名称相同就认定结果相同。

## 7. 输出具体判断，逐项保留推导

每项按这个顺序写：人物 → 原局依据 → 综合力量结论 → 对谁产生什么作用 → 具体应事推测。涉及动态层时，再附前层基础、本层变化及时间范围。

结果先用正常的话说清楚谁发生了什么，再展开依据。一个家庭问题可以有多个独立结论，但每个结论都要有自己的推导；不靠同义改写凑事项。判断保留为推测，不能将符号解释写成已经发生的事实。

## 8. 用反馈修正推导，保留修正前的判断

实际反馈与原判断分别记录。错在人物对应，回到人物模块修正；错在力量、作用关系或事件落点，定位到对应步骤修正，并记录版本。已知事实可以用于反推候选解释，但不能把事后拟合登记为事前命中，也不能将一个人的经历写成所有人的固定事件规则。
