# 0.14.0：修正重复应事

- 修正反向制约：原有要求制约来气同类时，保留行动受限路径，禁止变成人际协作。
- 支中同类根气不直接派生同辈；显干同类相接也不自动判协作或竞争。
- 日时只有重复生克关系而无冲合、承载变化或新接通组合时，留在背景，不每天重复列为近期应事。
- 保留独立候选及原局—逐层证据，但正文使用该路径的实际方向、受影响功能及条件，界面不再覆盖成固定类别句子。
- 展示本次新增冲合或承载变化；生入、取用既有补给、正向与反向约束分别解释。
- 新增行动受约束类型；校正记忆签名升级 seq6，避免沿用旧取事判断。历史原文保留。
- 验证使用合成命例；60 个流日比较实际可显示的事项类别集合，另覆盖反向约束、根气与参与者区别、重复关系及界面正文一致性。

构建与测试仅验证程序规则与回归，不证明命理预测准确率。本版没有接入语言模型，也不以随机换句制造差异。
