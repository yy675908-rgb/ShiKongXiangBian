# 0.7 分析改动与边界

保留原来的分析顺序、应事链及五行本质定义。本次修改的是原局认识、状态承接、作用依据和输出密度。

## 现有逻辑的问题

- 原局将生源、泄口、藏干并列罗列，没有明确后续需要观察的主要通路。
- 后续虽按大运到流时排列，实际主要将每层独立与日主相比；入场后的场并未成为下一层的分析状态。
- 地支冲合与天干生克混用；气势、体用和十神还会各自选择不同主层。
- 用字符串包含“生、克、合、散、堵”等词决定状态，复合描述容易触发错误分支。
- 默认展示重复说明，却未保留足够的入场前后依据。

## 现在的实现

`SequentialAnalysisEngine` 先建立只含四柱的原局状态：月令、本气/余气、透干、本气根/余气根、寒暖燥湿、来处和去处。根据这些证据选取一个候选观察轴；候选不能替代完整人工辨局。

每层严格只读取原局与此前已经进入的层。入场前、入场后均保存同一种状态：透出位置、根的位置与类型、时令、根受冲、显气相合、生源及制约通路。新增透出/补根、原承载新增冲合、其他承载加入、流月时令切换均记录为增量。前层冲合不因下一层入场而消失。

作用依据分为天干通道与地支通道。地支冲根取地支本气和相关藏干；支序齐全的三合/三会另列候选，未齐三刑、同支、自刑、整柱伏吟分别记录。合化、拔根、开库、解冲不自动成立；并存的关系保留供检查。

主层按与原局焦点相关的结构变化选择。单纯延续既有生扶的近端层，不自动覆盖前层补入的新条件。气势、体用、十神和应事共用一个主层及驱动干；最终翻译会再次读取全部层加入后的承载状态，避免沿用早层已经过时的条件。

首页先展示原局认识和连续主线。技术依据及详细状态可展开，完整记录仍保存。旧记录与旧记忆保留；新的记忆签名带规则版本、原局、时令和作用条件，不与旧的宽泛签名混合。

## 依据与工程解释

- [《子平真诠·论十干得时不旺失时不弱》原文](https://donglishuzhai.net/chapter/3719.html)：月令与通根分开看，得时/失时不能独立决定最终旺衰。
- [《滴天髓·地支论》原文](https://zh.wikisource.org/zh-hans/滴天髓/03)：冲的结果取决于双方条件，支中杂气和干支承接须分别讨论。
- [《滴天髓·寒暖、燥湿论》原文](https://zh.wikisource.org/zh-hans/滴天髓/16)：寒暖燥湿须结合承接与偏枯，不能由最后一干单独决定。

以上是传统取象规则的文本依据，不是预测准确率的实证依据。代码中观察轴的筛选顺序、`available` 的透根条件与冲合的待检标记是明确的工程简化，不能声称是经典唯一算法。土月的精确司令、争合与距离的完整效力、化气成败及实际事件的具体地点/时间仍未得到完整判断；证据不足时保留条件，不生成确定事件。

## 验证

JUnit 回归覆盖：原局不受后层污染、严格顺序与前缀稳定、状态连续、流月不改原局月令、地支冲合与天干分离、前层冲根持续存在、藏气与透出分离、三合齐支、三刑齐支、自刑/同支/伏吟、合不自动化、解释不解析显示字符串、输出主层一致、无动态时不捏造应期，以及真实排盘在节气/子时边界可分析。

这些测试验证计算与解释的一致性；实际解读质量仍需要独立命例及前后对照。
