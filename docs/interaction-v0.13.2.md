# 0.13.2 记录干支与文字整理

记录卡在查看日期下展示保存时的流年、流月、流日、流时，以及大运；本命四柱在展开后查看。新记录直接保存本次分析快照，不借用后来修改的本命、日期或子时设置。旧记录只读取已保存的逐层标题或摘要标题；缺失或冲突的干支不补算。搜索增加已保存干支，实际经过与旧记录原文不改写。

原始判断按原局、各层干支、可能事项分段，标题及依据、前提等标签加粗。每层相同的组合限制合并说明，保留全部生克方向。事项仍分别保留时间、过程、依据与前提，完整判断按需展开。

首页、逐层说明、气势、取象、主客体用、十神、应事依据与历史判断共用展示用语。例如“显性节点未齐”改为具体哪一五行未透出；“新增可用承接候选”改为“新增作用条件，实际效果待比较”；“承载受牵”改为“受冲合影响”。相关组合未齐时只列实际缺少的天干，同类组合不会因仅有日主而误写日主五行未透。

用语整理属于展示层，未改生克关系、原局与逐层顺序、十神定位、候选生成、评分、应期、成立条件或校正逻辑。不把“有根或得令”改写为作用必然成功。传统术语月令、通根、藏干、十神、合冲刑害破保留。实际经过与保存的个人记忆保持原文；历史原始文本不覆盖，阅读时整理格式。

回归核查子时两种日柱设置的快照保存、旧格式干支提取、冲突不猜测、分段加粗范围、组合重复说明合并、所有主事项与层次保留、全模块用语及作用方向、实际经过与个人记忆原文、同类缺失说明。界面与真实触摸操作仍需设备验收。
