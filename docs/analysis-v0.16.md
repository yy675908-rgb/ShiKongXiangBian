# 0.16.0：每一步产生累计结果，并成为后一步基础

> 历史实现记录：其中的应事理论已由[当前模块](analysis-theory.md)替换，不再作为有效规则。保留本文仅用于追溯实现与测试。

- 原局到大运、年、月、日、时持续累积；不将各层拆成互不关联的命盘。
- 每层保存当时全部既有路径的状态与后续作用。早层结果只读取截止该层的状态，不被未来日时回写。
- 取事在每个累计状态上运行。运年月不再因缺少日时触发而统一降为背景，前层仍有效的路径继续参加当前判断。
- 同一事项按新增、延续、调整、条件转好、暂缓、仍待定区分。来源不再具备条件时保留暂缓记录，不直接消失。
- 各层卡片展示累计结果；保存记录同时保留各步判断与依据。最终区展示最后一步的累计判断。
- 校正记忆签名 seq8。相同输入保持确定性，不随机换句。

验证重点：追加流时不能改写运年月日结果；年度结果不依赖日时；每步包含之前的路径、不能包含未来作用；后一步可改变前一步事项的当前状态。

范围：修正时间层级与状态传递，不宣称传统取象已获得经验证的预测准确率。单纯地支冲合仍不直接硬套具体物品或事故。
