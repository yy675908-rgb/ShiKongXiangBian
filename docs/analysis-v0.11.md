# 0.11 简明、有依据、有指向的分析输出

保留能量优先、逐层顺序及多事项预测规则。这次调整判断信息的组织与展示，不新增事件规则、概率或数量配额。

- 原局先给关键认识与后续需要检查的条件，五条完整通路、月令、根气和寒暖依据展开后查看。
- 各层直接从入场前后状态生成新增透出、添根、承载受牵或另有承载接入等变化；没有这些变化时说明实际作用方向。不重复展示变化、落点、承接和同一焦点的多段说明。层的状态仍只用当层前缀，后层信息不回写。
- 应事默认卡片回答可能发生什么、作用来自哪里、需要什么现实前提。精简措辞保留原有可能过程范围；完整成立/不成立条件、原局落点与逐层作用可展开。支气取实际藏干，受生路径按真实供给方向解释，不靠截断长文生成摘要。
- 时间标签复用候选自己的有效窗口状态；没有有效路径时显示应期待定，不因流时出现就写成该时必发。
- 排序较低的待补事项单独展开，全部待补时也保留这个入口，避免自动展示一屏依据不足的事项。数量不截断，人工核对仍列出全部候选。相反候选按标题指出其他条件下的可能，接续仅连接已展示事项。
- 气势、取象、主客体用、十神及预测前记忆统一放进推导明细。方法解释只在那里展示；无反馈时不显示空校正卡片。
- 保存时增加同一格式器生成的简明分析，同时保留完整原预测、全部候选和条件。记录默认看简明版，完整推导可展开；旧记录不改写。

`AnalysisOutputFormatter` 只读取结构化路径、承载和已有事项。推导时间线保留真实父路径，同柱同干的天干与地支端点不合并。格式化不读取实际事件，也不改变预测签名和排序。

验证覆盖原有命理逻辑，新增检查简明时间标签不抬高受阻流时精度、支气摘要不借错入场天干，以及精简落点保留同一原局干的不同通道。本地项目 Kotlin 2.0.21 执行 `testDebugUnitTest assembleDebug` 通过：49 项测试，0 失败、0 错误；生成 0.11.0（versionCode 11）调试包。另用合成四柱检查实际格式器的简明输出，未使用用户已发生事件反推预测，也未验证实际应事准确率。
