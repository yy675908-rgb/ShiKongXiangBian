# 0.13 组合气势先于十神人事

按原局→大运→流年→流月→流日→流时保留六层方法。每层保存完整组合状态，比较进入前后通路条件；最后一层不改写原局和早层状态。先认识来源、承载、流向、耗用和制约，再翻译十神与多项可能应事。

显性组合分别检查补给→主体→输出、主体→输出→资源、约束→补给→主体、资源→约束→主体、输出制约约束、补给制约输出、同类分用资源、资源制约补给。供方、中间节点与受方逐一保存具体干气端点及承载，缺节点、未透、受牵或承载不足时，不声称整链已通。主体位置始终使用实际日干，不能借比劫的承载替主体兑现输出。

同一十神的定位服从它参与的通路：支持也可能限制表达；要求可以经支持转接，也可能直接约束；产出可接资源，还须交易或实际接收；资源可推动责任或制约补给。保留生方泄用和施制方耗用，不凭组合名称直接判贵、富、制住、夺食或吉凶。十神保留阴阳名称，解释以当时的实际功能为先。

逐项应事匹配同一组真实端点，不用一个焦点概括所有事项。同一显性承受端若同时有可参与的制约方，补给类事件加入组合条件，原先符合重点条件的候选降为次要可能；不能由此直接判制住、失败或全部同类事项受阻。反向补给按真实受方定位，支气通道不借显干释放。预测仍不读取实际反馈。

页面下排标注“此时 · 已应用的查看日期”，编辑未应用的时间草稿不会改写此时标签。分析顺序与应事链的展开入口位于排盘之后、原局之前，首页先显示原局整体通路及关键点，再显示逐层新增气势变化和具体事项。完整组合、十神解释与技术依据分别展开，不增加应事条目间空白。

这些通路是传统命理框架中的定性候选，显性承载不等于相对强弱已经确定。隐支作用仍由原有独立路径处理，不能用显干组合代替支中同干；显性节点齐全不证明距离、先后、制化或现实效果。没有引入数量积分、唯一旺衰、自动合化或统计命中概率。此次验证覆盖具体中间节点、主体不能借同类承载、潜藏节点、不同通道、反向受方、早层不可被未来改写、实际组合排序和显示条件；构建结果另见 PR 验证记录。
