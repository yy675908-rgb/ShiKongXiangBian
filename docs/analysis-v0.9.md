# 0.9 路径承载、作用先后与应事纠偏

分析顺序、应事链与五行本质保留；本轮修正的是具体作用是否仍能承接、独立支线的遗漏，以及从技术关系到事件方向的过度简化。

## 核查后修正的问题

- 原先把日主自合也记为合绊/合去。现在分别标记日主自合、旁干牵合及多干合意待判；自合官气转为约定/责任条件的候选，不由自合直接推出被迫或处罚。旁干存在时仍保留竞争路径，距离和先后未判完不能自动断合去。
- 原先只保存五行整体的承载，别处同五行未受牵可能掩盖当前干气本身被旁合。现在每条路径单独保存入场前作用端、入场后来源/作用端、全链后来源/作用端；天干牵合在该干的位置核查，地支通道不机械借用天干被合的标记。
- 后层普通生克原先只有与日主相接的默认路径，独立的食伤生财、食伤制官杀、财作用印等可能漏掉。现在追加显气对前场显气的普通生入、制约路径，天干和地支仍分开。所有支线都保留原局落点，后层只继承同干、同通道的前层路径。
- 后层对早层来源的克制、旁合或支气受扰另行记录。它们不被当作来源必然失效，但早层支持也不能未经复查继续列为高优先级；当前规则将这些来源留为条件待检。
- 原先同支/伏吟也能直接生成休息被打断。现在单纯再现不生成这项负面事项，须另有冲刑害破的作用依据；这仍只是日常过程的条件候选，不能等同必然失眠。
- 六合不再直接按阻滞解释。只有实际制约、旁干牵合或其他受扰关系才进入受阻候选，仍须看作用承载及现实条件。
- 三合/三会的新路径取实际入场支中属于该组五行的藏干，避免拿另一成员的藏干代替入场来源而弄错偏正十神。仍不自动合化。
- 分组的时间窗口取仍具承接条件的路径；较晚的受牵路径不能借较早可用路径宣称较晚时辰已触发。没有可用来源时明确应期未定。
- 同领域相反候选须有相同原局干气及通道的端点，不能仅因为在同一柱就把干和支的不同事项判成矛盾。默认卡片补充本项干支作用摘要；隐藏待补事项时也隐藏指向它们的接续，完整记录仍保存。

上述改动不会用实际事件反向选择候选，不设事项数量配额，也不把结构排序当作统计概率。seq3 签名区分本轮路径条件；旧记录保留。

## 文本依据和工程边界

- [《子平真诠·论十干合而不合》](https://www.donglishuzhai.net/chapter/3718.html)：区分本身之合与被别干合去，同时讨论隔位和多干合意。因此不能把所有合一律写成主体受阻。
- [《子平真诠·论生克先后分吉凶》](https://www.donglishuzhai.net/chapter/3733.html)：相同生克配置，先后位置会改变取法。本章讨论的是四柱配置；本项目逐层入场后的复查是工程扩展，不能说原文规定了这里的日时算法。

现实过程模板、自合到任务约定的取象、来源受后层作用时的保守降级，以及近端排序仍属工程解释。没有完成精确司令、距离/先后效力、争合成败、双方相对强弱及化气判定，不宣称已能锁定具体人、地点或物种，也不宣称已验证预测准确率。
