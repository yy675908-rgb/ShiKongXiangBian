# 0.13.1 提示条与历史记录操作

保存成功提示明确使用短时显示，避免带“看记录”动作时默认无限期显示。所有提示支持左右滑动关闭、关闭按钮、返回键；切换页面时收起提示。删除撤销提示使用较长但有限的显示时间，同时记录页保留“撤销上次删除”，因此提示关闭后仍可撤销本次删除。新的提示各自建立滑动状态，上一条的位移不影响下一条。

历史记录每项提供展开、复制、删除。默认显示日期、校正状态和两行实际经过，完整内容按需展开，不截断存储或复制内容。支持按日期、实际经过、校正结果搜索，清空按钮及无匹配时返回全部记录。保存后点“看记录”会清空筛选并显示列表顶部；普通切换页面保留搜索与阅读位置。

删除只清理历史记录，校正记忆另存且保留，页面明确说明这一范围。根据稳定条目 key 删除具体记录，相同文本的重复记录各自独立；保存新记录保留现有条目 key。删除及恢复均在后台写入成功之后才改变列表，失败保留原状态并可重试。保存、删除、恢复共用互斥的写入状态，防止旧快照覆盖新数据。

撤销恢复上次删除的完整原文和原位置，利用相邻条目 key 定位；若期间保存了新记录，恢复时保留新记录及当前校正记忆，不恢复过时的整个列表快照。后一次删除替换前一次的撤销入口，旧提示不能撤销新删除。撤销暂存于会话的 ViewModel，退出进程后不保证可撤销；已完成的删除及恢复写入现有持久存储。

记录、设置页返回键先关闭提示，再回取象页。复制仅在用户点击时将完整记录放入系统剪贴板。分析、组合气势、十神解释和预测规则未作改动。

新增回归覆盖精确删除重复项、持久化后重新加载、失败不改列表、撤销失败重试、保存新记录后撤销不丢新数据、写入互斥、失效撤销与过期提示、搜索范围及旧格式兼容。手势和界面仍需设备验证，单元测试不代替真实触摸验收。
