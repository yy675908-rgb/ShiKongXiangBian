# 0.10 先看能量本质，再用传统命理定位和取象

分析顺序和应事链保留。这里的“本质”是来源、承载、流向、传递中的耗用、制约及后续补给，不止五行属性词。能量是本项目的定性取象状态，未建立物理能量计量模型。

## 文档学习

通读用户提供的《传统命理(1)》后，吸收以下理解方式。这里只保存方法归纳，不上传原文、授课者身份或私人命例。

| 文档讨论的位置 | 方法 | 项目中的处理 |
| --- | --- | --- |
| “格局”、月令与七个原局字 | 先认识原局的搭配，再看外来字作用谁 | 主观察轴保留，同时建立五条原局功能通路，不能把一个调候问题当作所有事项的基础 |
| 明字/暗字、藏干与透干 | 已在原局显露、仅潜藏和外来补入须分开 | 原局完整保存透根与端点；潜藏节点不直接列为显性通路已接通，不凭空补原局缺字 |
| 日主生克的耗泄、食伤生财、官杀印枭与食伤制杀 | 不仅看某神出现，还看谁在供给、谁在消耗、谁在约束谁 | 用结构化关系判实际作用方向；得生路径中的供方是既有端，不能用受方有根替供方确认输出能力 |
| 印枭、财才、食伤段落的组合解释 | 同类十神可有不同结果；生扶不必获益、克制不必受害 | 每项展开作用、耗用和边界，再定位人事；不把“财旺”直接等同有钱、“官杀出现”直接等同压力 |
| 末段“所有保护我们的人事物……” | 人事定位服从当时的功能，同一个人的身份不能固定为某神 | 保留补给、任务、输出、资源等条件性事项；不只凭母亲/老师/领导等身份生成事件 |
| 流年、流日、流时段落 | 背景与近端细节分层理解；不同事项各有承接 | 运年月至日时顺序保留，不要求一切细节都由一个流日焦点概括，也不直接把流时关系判成必在该时发生 |

文档还包含相互不同的门派取法。没有把“月令生扶便身旺”“所有库逢冲便开、逢合便锁”“化不成仍一律增加化神”写成无条件算法；库中载气、冲合、时令、透出、争合及双方承载仍须分别检查。十二长生可作状态与阶段描述，不能仅凭“病”“死”“绝”等字生成疾病、灾祸或具体事件。司令分日口诀仅作为来源明确的门派材料保留，目前未实现节气内的精确分日判定。

文档中的行星、量子纠缠、姓名或颜色改运等解释不作为程序因果依据；医学取象和药物建议不进入预测规则。

## 实现

- 原局五条通路分别保存节点、方向和显性承接条件：补给→主体→输出，主体→输出→资源，约束→补给→主体，输出制约约束，资源制约补给。它们是需核查的结构候选，不是已证明全链畅通或已定格局。
- 原局保存每个干气与通道的独立承载。逐项基础不再借别处同五行未受牵的状态，掩盖本干旁合；天干和支中同干的记录也分别保留。
- `EnergyEssenceInterpreter` 区分共享、向外传递、取用既有补给、向外制约和受既有端约束。各项显示实际方向与耗用；五行性质和十神位于作用解释之后。
- 排序检查实际施生/施制端。输出之气虽已透且有根，若主体供给未接通，不因此升为近期可用输出路径；有技术关系也须核查供方根气，不能绕过供方承载。候选仍保存，供给待补时保留待检及应期未定。
- 官杀直接作用主体保留任务/规则事项候选，但不预设负担或催办。该项定位为条件变化，有序推进还是额外负担须看主体承接与其他通路；自合官气的约定候选保留。
- 原局整体认识、逐项能量过程和人工反馈一同留档。预测不读取实际事件文字。`seq4` 签名纳入双方承载条件，与旧版记录分开；旧记录仍保留，空候选不靠领域重合算命中。

没有新增事件数量配额或把通路排序当作概率。相对强弱、制约成败、距离先后、合化与司令尚不能由这些定性承载条件单独判定。这里完成的是原局认识和作用方向的纠偏，实际准确度仍待前瞻核验。
