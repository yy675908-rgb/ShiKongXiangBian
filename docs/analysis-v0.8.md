# 0.8 多事项应事与逐项验证

保留时空 → 能量关系变化 → 气象 → 主客体用 → 十神 → 应事的顺序、应事链和五行本质。主线概括继续说明原局主要承接矛盾，具体应事则分别读取全体路径，不能用一个主层代表所有可能事项。

## 从原局到多项事件

1. 原局认识在任何外来层进入前形成，另保存五行各自的透根、时令和受牵状态。
2. 大运、流年、流月、流日、流时依次进入。每层分别保存天干作用与地支藏干端点，既保留主线，也保留独立支线。
3. 后层作用前层时，只有前层同一干气、同一通道已经接到本命，才继承其原局落点。不能因层名相同就借用全部前层路径。
4. 每项候选保留原局基础、参与路径、逐层承接、本项体用/十神、最后的承载状态，随后转为具体过程候选：例如临时调整位置/路线、钱物调配或结算反复、解释交涉、返工、补核资料、追加任务、协调分配等。
5. 同一领域与过程的重复说法合并，全部承受点和证据仍在展开内容及记录中。没有固定事项数量，也不强制填满领域。潜藏而未显的十神不会机械展开全部人事类型。
6. 共享确切路径的事项可以形成条件性接续；没有共享路径，不因为领域接近就编成因果链。接续必须以首项实际发生、并需要相应后续处理为条件。

主线概括与每项推导各有用途：主线解释本命当前主要变化，各项解释不同端点可能落实的过程。候选内部的两个过程例子是同类事项的替代具体化，不能计成两个独立命中。

## 排序、时间与相反通路

优先关注须有同一端点在不同层重复承接、日/时接入、结构变化和相对清楚的显性承载。其他近端路径次之。远期背景、来源受牵或潜藏端点保留为条件待补。只给大运的输入不能定位当日；三合/三会齐支和未齐三刑不被当作已经完成的化局或完整刑局。

同领域同承受点同时存在补入与受阻时，保留两项及各自条件，不把相反候选都列成高优先级。排序是可审查的结构规则，不是统计概率；具体日期、地点、人物、物种、液体或损失数额不得从有限干支直接锁定。

## 原始预测和反馈

实际文本不参与原局或应事生成。页面允许逐项勾选实际出现的候选；结果标为人工确认，并保存确认项数与编号。未勾选表示尚未确认，不能当作已否定；领域文字相似也不能自动记为具体应事命中。

完整记录保留所有原始候选、证据、条件和接续。seq2 签名含独立路径结构；旧记录原样保留，不与此前宽泛规则签名混用。本轮没有以实际事件反向选择模板或训练权重。

## 依据与仍待验证的内容

- [《子平真诠·论宫分用神配六亲》](https://www.donglishuzhai.net/chapter/3736.html)：宫位与十神的人事含义须结合使用，不能只见某个十神就锁定一件现实事。
- [《三命通会·卷五》](https://zh.wikisource.org/zh-hant/三命通會/卷五)：十神建立在五行生克与阴阳关系上，作为传统人事取象的基础。
- 透根、月令、冲合和寒暖依据沿用 [0.7 说明](analysis-v0.7.md)。

以上经典不能直接证明本项目每条现实过程模板。宫位到空间/用品及日常安排的取象、显性承载门槛、近端窗口、去重和优先级均是工程解释，需要独立命例修订。尤其地支受扰并不能必然推出环境故障或休息受扰；这些只是有现实使用过程时的替代候选。仍未完整计算司令、争合距离、合化成败和双方效力，不宣称已经达到精准预测。

回归测试验证多领域并行、不受摘要主层筛选、原局与后层隔离、相同通道继承、藏干保留与显隐筛选、重复合并、远期不冒充近日、共享路径才接续，以及逐项反馈不回写原始预测。Android 单元测试和应用构建用于确认逻辑及页面可编译；预测质量需另做预先冻结候选、到期逐项核对的前瞻验证，并同时统计未发生候选与未覆盖实际事项。
