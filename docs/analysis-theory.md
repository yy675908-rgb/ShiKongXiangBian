## 依赖与维护

人物对应的结果传给应事模块；应事使用原局及各层综合力量结论，不能用事件结果反向改写人物。力量评估的具体算法与人物判定规则不在本次伪装为已完成。

新增理论先确定负责的问题、输入和输出，再建立独立模块；同一规则只保留一个归属。修改已存在规则时更新原模块和版本，删除被替代的当前条目，不在末尾累加互相矛盾的解释。案例和反馈不直接升级成通用规则。

## 旧理论替换

README 和 App 原有的统一“应事链”说明已被这组模块替换。旧版文档中的十神转固定人事词、单条路径直接出事件、以生克标签代替综合力量结论等做法，均不再是当前应事理论。analysis-v*.md 仅作历史实现与测试记录，不能与本索引并列作为有效规则。
