# 0.15.0：删除缺乏依据的具体应事

0.14.0 仍把地支冲合与继承的日/时柱落点映射为搬动、用品异常和休息受扰，再用共享路径拼接后续事件。增加作用说明没有修正这些推断。本版直接删除这些取事规则。

- 地支关系继续保留在原局与逐层分析中，不直接生成现实事故、搬动或休息事件。
- 动态层之间的接触即使继承了本命落点，也不能代替直接、本命、显干路径生成事件。
- 相同类别只有本命受作用端一致时才能合并证据。不同落点不能相互借用日时触发与承载条件。
- 同类受到官杀约束不证明主体本人已经行动受限，此候选也归入待补。
- 共享象征依据不证明现实因果次序，删除固定事件接续。
- 首页卡片只保留标题、观察窗和一段简短方向解释；变化、依据和条件收进展开项。删除固定类别后果段落及“同类承载”等重复正文。
- seq7 隔离新旧校正记忆，旧记录仍保留原文。

验证包含合成冲合、间接继承、不同落点、确定性与跨日回放。另提供仅从运行参数读取命盘的本地 JVM 回放工具，私人命例无需提交到仓库或 CI。

边界：这次修正删除了无依据的应事和固定接续，不是引入了经验证的预测模型。减少错误候选可能导致部分时点没有近期事项；不以随机换句或虚构事件填满界面。相同命盘、相同时辰输入应得到一致结果。
