# 时空象变 · ShiKongXiangBian

Android 端四柱分层分析与应象记录工具。当前版本为 **0.8.2**。

## 分析顺序

1. 先建立本命基线：月令、日主、根气、生源、泄口与明暗结构。
2. 按“大运 → 流年 → 流月 → 流日 → 流时”逐层加入；用户可选择分析截止层级。
3. 每层分别计算天干显层、地支基础层及成组结构。
4. 完整保留同一动态支作用到多个本命宫位的证据，不用单一最高权重关系覆盖其余关系。
5. 先由宫位给出生活领域，再用十神补充主题；输出多个候选及成立边界。
6. 冲、刑、合、害、破描述作用方式，不直接等同于吉凶、疾病或具体事件。

## 0.8.2 场景翻译

- 新增“场景翻译”层，按“当前层直接证据 → 宫位 → 十神主题 → 现实候选 → 成立边界”输出，不再把领域候选直接写成具体事件。
- 年柱受冲只落到外部圈层与远端人际，不用于判断搬家、驻点、轮转或更换单位。
- 月柱或日柱受到冲、刑、破，并同时连接印、官杀等制度主题时，将轮转、调岗、驻点或地点变化升级为强候选。
- 月柱、日柱只有合、害等连接时，优先解释既有安排中的协调、适应与磨合；迁动仍保留为低位候选，等待流日、流时或其他证据加强。
- 当前流月未直接作用本命四支时，标记为承接层；月层本身不足以确定项目启动、关系建立、环境改变或结果落定，但不排除更细时层触发。
- 食伤与成果宫同时出现只表示执行、表达和输出增强，不直接等于项目启动、完成或通过。

## 0.8.0 主要变化

- 三合、三会形成的五行继续换算为十神主题，不再只按参与的本命宫位落点。
- 新增综合应事层：优先寻找能同时解释多个宫位的核心事件。
- 可识别教育/职业身份转换、环境圈层迁移、关系建立、生活结构调整、成果输出和资源变化。
- 女命官杀结构同时保留制度身份与感情关系两条应事路径。
- 修正年柱发动时将父母家庭机械排在社会环境之前的问题。

## 0.8.1 近时交流候选

- 流月、流日、流时明干同时连接印、比劫、食伤时，增加“同辈交流与信息讨论”为条件性候选。
- 该候选只表示同辈、信息与表达三条路径在近时层相接，不固定为课题交流，也不覆盖其他应事。
- 实际事件校正可同时保留师门人际与学业工作两个领域。

## 0.7.0 基础重构

- 新增流年、流月、流日、流时范围选择，细时层不覆盖上层结论。
- 分开呈现天干与地支，区分公开方向和现实基础的变化。
- 新增半合、三合、三会、三刑及四墓库组合识别。
- 同时列出年、月、日、时柱的宫位发动及证据。
- 历史应象改为多领域标签，并按结构相似度提供参考。
- 原始预测、实际事件和事后校正分别保存，历史记录不反写原判断。
- 增加核心规则单元测试。
