# 时空象变 · ShiKongXiangBian

一个以“象”为核心的个人时空取象记录与验证 App。

## 核心逻辑

不是统计五行数量，也不先套固定格局。

主链：

**时空 → 能量关系变化 → 气象 → 主客体用 → 十神 → 应事**

先看能量本质：来源、承载、传递、耗用、制约和续接；五行是描述方式，十神按作用定位。原局先形成整体认识，后层分别改变已有通路，各项应事保留自己的依据与条件。

### 气势
- 谁在起势
- 谁在退
- 谁被引动
- 谁被压制
- 能量往上、往下、往外、往内
- 是聚还是散
- 是通还是堵
- 是温化、寒凝、燥烈还是湿滞
- 是显化还是潜藏

### 应事判断
- 事情类型
- 领域
- 时间
- 空间
- 显性 / 隐性
- 主动 / 被动
- 内部 / 外部
- 开始 / 发展 / 转折 / 结束

## 第一版范围
- Android 原生 App（Jetpack Compose）
- 本命出生时间、性别设置
- 指定任意实时时间或一键取当前时间
- 本命四柱、流年、流月、流日、流时
- 以本命日主为参照计算动态十神
- 藏干、十二长生
- 干支合冲刑害破等关系提示
- 气势观察框架
- 事件输入与当天取象记录工作台

> 当前版本先把“准确排盘 + 分析骨架 + 数据入口”做稳。后续再把大运、神煞、象数词典、个人统计与前瞻预测逐层加深。

## 0.7 分析优化

保留分析顺序、应事链与五行本质；先形成原局认识，再逐层保存并承接透根、时令与冲合状态。气势、体用和十神共用同一主层；首页展示主线，详细依据可展开。

说明与依据见 [分析改动与边界](docs/analysis-v0.7.md)。

## 0.8 多事项应事

应事按全部独立作用路径并行生成，不再只给一个主落点。每项展示可能出现的具体过程、观察时间、成立条件，以及原局基础 → 逐层承接 → 本项体用/十神的依据。同类重复合并并保留来源；共享依据的后续事项只作条件性接续。

实际反馈逐项人工确认，领域重合不自动算命中。结构排序不等于经验命中率，解读质量仍需前瞻命例验证。

说明见 [0.8 应事优化](docs/analysis-v0.8.md)。

## 0.9 路径纠偏

区分日主自合与旁干牵合；逐项复查本干承载及后层制约，补入普通生财、制官杀等独立支线。纯同支/伏吟不直接推出休息受扰，六合不直接推出阻滞。应期按仍可承接的路径确定，首页每项展示自己的干支依据。

说明与验证见 [0.9 路径纠偏](docs/analysis-v0.9.md)。

## 0.10 能量本质与原局整体认识

原局并列检查补给与输出、输出与资源、约束经补给转接、输出反向制约、资源对补给的制约。每项回到具体原局干气和通道，先说明实际施生/施制方向及耗用，再翻译人事。来气受原局所生时复查原局供方，不能因来气有根就提高输出事项的优先级。

说明、文档学习取舍与验证见 [0.10 能量本质](docs/analysis-v0.10.md)。

## 0.11 简明分析输出

首页按原局关键点 → 每层新增变化 → 具体可能应事阅读。每项直接展示可能过程、实际作用依据和场景前提；完整条件、逐层来源及技术记录按需展开。待补事项可单独查看，记录同时保存简明版与完整原预测。

说明见 [0.11 输出优化](docs/analysis-v0.11.md)。

## 0.12 操作与流畅度

排盘、分析和完整记录整理移到后台；快速切换日期只显示最后一次结果。页面保留滚动位置、展开状态及未保存草稿。增加日期时间选择、前后一天、严格日期校验；输入草稿点查看或保存后才应用。记录与校正记忆一起保存，防重复点击，失败保留输入，成功可直接看记录。

说明与验证见 [0.12 操作优化](docs/interaction-v0.12.md)。

## 0.13 组合气势与十神作用

先检查多种能量的实际接续、耗用和牵制，再解释组合中的十神。每层保存独立组合状态和新增变化；应事按自己的端点检查整体条件，同一承受端补给与制约并见时，不直接升为重点。排盘下排标为“此时”，分析顺序与应事链入口放在原始信息之后。

方法与边界见 [0.13 组合气势](docs/analysis-v0.13.md)。

## 0.13.1 记录与提示操作

提示条支持左右滑动、点关闭和自动收起。历史记录支持搜索、折叠、复制、删除和撤销；删除/恢复失败保留原状态，写入相互协调。保存后“看记录”显示最新记录，返回键可先关闭提示再回取象。

说明见 [0.13.1 操作整理](docs/interaction-v0.13.1.md)。

## 0.13.2 记录干支与文字整理

记录显示当时的流年、流月、流日、流时及大运；旧记录从保存内容提取，不用当前本命补算。原始判断分段加粗，全模块统一简明用语，同层重复条件合并；保留原有分析顺序、判断条件及各项应事。

说明见 [0.13.2 文字整理](docs/interaction-v0.13.2.md)。
